# SRP — Simple, Readable, Parseable

**Surveys for humans and machines.**

SRP is a plain-text domain-specific language for writing surveys. It reads like plain English, handles complex survey logic without configuration UIs, and is designed to be written by people or generated by AI.

Learn more and try it at **[srp.solutions](https://srp.solutions)**.

---

## What it looks like

```ruby
page "intro" do
  title "Quick Product Survey"
  text "Thanks for taking a moment to share your feedback."
end

page "main" do
  title "Your Experience"

  SingleSelect "satisfaction" do
    text "How satisfied are you with our product?"
    required

    option "Very satisfied"
    option "Satisfied"
    option "Neutral"
    option "Dissatisfied" do
      action :skip_to, "followup"
    end
  end

  NPS "recommend_score" do
    text "How likely are you to recommend us to a friend?"
    add_why_field
    required
  end
end

page "followup" do
  title "Tell Us More"

  Discussion "improvement_feedback" do
    text "What would make you more satisfied?"
    required
  end
end

page "end" do
  title "Thank you!"
  action :complete
end
```

## Key concepts

**Pages** are the top-level structure. Each page is shown to the respondent one at a time.

**Questions** live inside pages. Over 35 question types are available — from simple text inputs and multiple choice to heatmaps, card sorts, conjoint choice, and MaxDiff experiments.

**Actions** control survey flow: skip to a page, complete the survey, or terminate (screen out) a respondent based on their answers.

**Segments** tag respondents based on answers. `show_only_if` then uses those tags to conditionally show pages or questions — no complex branching trees required.

**Text piping** lets you reference earlier answers inline: `"You mentioned {{favorite_product}}. Tell us more about it."`

| Category | Types |
|----------|-------|
| Text input | `OpenEnded`, `Discussion`, `Number`, `FillInTheBlank`, `Autosuggest` |
| Selection | `SingleSelect`, `MultiSelect`, `Dropdown`, `ButtonCheckbox`, `ButtonRating`, `ThisOrThat`, `Ranking`, `EmotionSelector` |
| Matrix | `SingleSelectMatrix`, `MultiSelectMatrix`, `RatingMatrix`, `SingleSelectBipolar`, `SingleSelectBipolarMatrix`, `OpenEndedMatrix` |
| Scale | `Rating`, `Slider`, `NPS` |

| Other | `DatePicker`, `MediaUpload`, `Notification` |

- **`examples/`** — working `.srp` files covering each question type and common patterns.

---

## Using SRP with AI

The `language_reference.md` file is the full spec and is sized to fit comfortably in a context window. To have an AI write or edit a survey:

1. Paste `language_reference.md` into your prompt (or attach the file).
2. Describe the survey you want.
3. The AI will produce a valid `.srp` file.

The examples directory has real files you can use as few-shot examples alongside the spec.
